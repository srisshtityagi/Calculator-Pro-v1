# 🧮 Calculator Pro V1

## 📌 Description

Calculator Pro V1 is a menu-driven console application developed using *Java*. It performs a variety of mathematical operations while handling different edge cases and invalid inputs. This project was built to strengthen my understanding of Java fundamentals and improve my problem-solving skills through practical implementation.

---

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Square of a Number
- Cube of a Number
- Power (xⁿ)
- Factorial
- Prime Number Check
- Maximum of Three Numbers
- Minimum of Three Numbers
- Average of Three Numbers

---

## Input Validation

The calculator also handles several edge cases to ensure reliable execution.
- Prevents division by zero.
- Prevents modulus by zero.
- Restricts factorial for negative numbers.
- Correctly handles prime number cases for 0 and 1.
- Displays an appropriate message for invalid menu choices.
- Allows users to perform multiple calculations without restarting the program.

## Project Flow

1. Display a menu of available operations.
2. Take the user's choice.
3. Accept the required input(s).
4. Perform the selected operation.
5. Display the result.
6. Ask the user whether they want to continue.
7. Repeat until the user chooses to exit.
